# あつ森 売値サーチ

『あつまれ どうぶつの森』（北半球）の虫・魚・海の幸・化石・DIYで作れるものの売値と取得状況をすぐに調べられる、図鑑型の検索ツールです。

**公開ページ：https://on6848.github.io/acnh-uriyaku-search/**

スマホのChromeで開いて「ホーム画面に追加」すると、アプリのようなアイコンから起動できます（PWA対応）。

ヘッダーのナビゲーションバーから「生き物」「化石」「DIY」の3ページを切り替えられます。

## 生き物ページ（トップページ）

- 虫・魚・海の幸のカテゴリ別に一覧・検索
- 名前での検索（ひらがな入力にも対応、例：「か」でカ行の名前がヒット）
- 検索時は完全一致を最優先で表示し、部分一致はクエリが名前の何文字目に出てくるかで並べ替え（同じ位置の中では選択中のソート順を適用）
- 価格の高い順・安い順・名前順のソート
- 出現月・出現時間帯での絞り込み（時間帯は具体的な時刻の範囲つき）
- 「今月獲れるものだけ」「今の時間に獲れるものだけ」の絞り込み（現在時刻と連動）
- 獲れる場所での絞り込み（魚：川・池・海・桟橋など／虫：地面・広葉樹・針葉樹・ヤシの木など）
- レア度を★1〜5で表示（カテゴリごとの価格分布から算出）
- 捕まえた／逃した済みのチェック管理（このページを閉じると消える一時的なメモ）
- 複数の生き物を選んで売値を比較（棒グラフ表示、上限なし）

## 化石ページ

- 化石73種類（単体のもの14種＋骨格などの仲間21グループ）を売値つきで一覧表示
- 「仲間ごとにまとめる」表示で、Tレックスやトリケラトプスなどの骨格が何個中何個そろっているかをひと目で確認（コレクションが全部そろうとトロフィー表示）
- 名前での検索（ひらがな対応）、売値順・名前順のソート
- 収集済みの行をタップ／クリックするだけでチェックでき、状態はブラウザに保存されて次に開いたときも残る
- 円形の進捗リング、達成バッジ（10種・25種・50種・コンプリート）、全73種コンプリート時の演出など、収集を楽しめるUIつき

## DIYページ

- DIYレシピで作れるもの全924種類（家具・壁掛け家具・雑貨・料理・道具・床・ラグ・壁紙・天井・身につけるものなど）の売値を一覧表示
- カテゴリ絞り込み、名前検索（ひらがな対応）、売値順・名前順のソート
- 各アイテムに必要な材料と個数を表示
- 「材料でさがす」に切り替えると、材料名やグループ（貝がら・鉱石・お花・くだものなど）で絞り込み可能。「貝がらを使うレシピの中で高く売れるもの」のような探し方ができる
- マイデザ機能の柱・仕切りカウンターなど、そもそも売却できないアイテムは「売却不可」と表示
- 売値はレシピカードではなく、作った完成品をタヌキ商店で売却したときの基本価格

## 技術

- 依存ライブラリなしの単一HTMLファイル（`index.html` / `fossil.html` / `diy.html`）。サーバーサイド処理は無し
- PWA対応（`manifest.json`、`sw.js`、アイコン一式）
- 化石ページの収集状況は `localStorage` にブラウザ内保存（保存できない環境では一時的なメモにフォールバック）
- 生き物・化石のデータはCritterpedia準拠の出現データや各種攻略サイトの情報を、DIYのデータはコミュニティのデータマイニング情報（npm「animal-crossing」パッケージ）を基に作成・検証

## データについて

木にとまる虫の分類（広葉樹／針葉樹／ヤシの木）や、魚の釣り場（桟橋を含む）、化石の売値・部位構成、DIYの売値などは複数のソースを突き合わせて検証しています。ゲーム内の実際の仕様と差異があれば修正します。
