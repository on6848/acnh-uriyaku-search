# あつ森 売値サーチ

『あつまれ どうぶつの森』（北半球）の虫・魚・海の幸・化石・DIYで作れるもの・洋服やアクセサリーなどの衣装の売値と取得状況をすぐに調べられる、図鑑型の検索ツールです。

**公開ページ：https://on6848.github.io/acnh-uriyaku-search/**

スマホのChromeで開いて「ホーム画面に追加」すると、アプリのようなアイコンから起動できます（PWA対応）。

ヘッダーのナビゲーションバーから「生き物」「化石」「DIY」「衣装」の4ページを切り替えられます。

## 生き物ページ（トップページ）

- 虫・魚・海の幸のカテゴリ別に一覧・検索
- 名前での検索（ひらがな入力にも対応、例：「か」でカ行の名前がヒット）
- 検索時は完全一致を最優先で表示し、部分一致はクエリが名前の何文字目に出てくるかで並べ替え（同じ位置の中では選択中のソート順を適用）
- 価格の高い順・安い順・名前順のソート
- 出現月・出現時間帯での絞り込み（時間帯は具体的な時刻の範囲つき）
- 「今月獲れるものだけ」「今の時間に獲れるものだけ」の絞り込み（現在時刻と連動）
- 獲れる場所での絞り込み（魚：川・池・海・桟橋など／虫：地面・広葉樹・針葉樹・ヤシの木など）
- レア度を★1〜5で表示（カテゴリごとの価格分布から算出）
- 捕まえた／逃した済みのチェック管理（このページを閉じると消える一時的なメモ）
- 複数の生き物を選んで売値を比較（棒グラフ表示、上限なし）

## 化石ページ

- 化石73種類（単体のもの14種＋骨格などの仲間21グループ）を売値つきで一覧表示
- 「仲間ごとにまとめる」表示で、Tレックスやトリケラトプスなどの骨格が何個中何個そろっているかをひと目で確認（コレクションが全部そろうとトロフィー表示）
- 名前での検索（ひらがな対応）、売値順・名前順のソート
- 収集済みの行をタップ／クリックするだけでチェックでき、状態はブラウザに保存されて次に開いたときも残る
- 円形の進捗リング、達成バッジ（10種・25種・50種・コンプリート）、全73種コンプリート時の演出など、収集を楽しめるUIつき

## DIYページ

- DIYレシピで作れるもの全924種類（家具・壁掛け家具・雑貨・料理・道具・床・ラグ・壁紙・天井・身につけるものなど）の売値を一覧表示
- カテゴリ絞り込み、名前検索（ひらがな対応）、売値順・名前順のソート
- 各アイテムに必要な材料と個数、そのDIYレシピ自体の入手方法（住民から／タヌキ商店で購入／季節イベントの限定NPCから／特定の魚を釣った報酬　など）を表示
- 「材料でさがす」に切り替えると、材料名やグループ（貝がら・鉱石・お花・くだものなど）で絞り込み可能。グループは複数同時に選べ、複数選んだ場合はそのすべてを使うレシピだけに絞り込まれる（例：貝がら＋鉱石を両方ONにすると、貝がらも鉱石も両方使うレシピだけが高く売れる順に並ぶ）
- 「コンセプトでさがす」に切り替えると、「海辺リゾート風」「和風」「きらきらゴールド」のようなテーマの言葉を入力（またはテーマのチップをタップ）して、それっぽいDIY候補を一致度順に表示。あらかじめ用意したテーマ辞書とキーワードによる簡易的な絞り込みで、本物のAIが自由に発想しているわけではない（AI APIは一切使用していない）
- マイデザ機能の柱・仕切りカウンターなど、そもそも売却できないアイテムは「売却不可」と表示
- 売値はレシピカードではなく、作った完成品をタヌキ商店で売却したときの基本価格
- 材料をDIYせずそのまま売った場合の合計売値（材料価格の内訳つき）と、完成品を売った場合との差額（DIYした方が得か損か）を各アイテムに表示。カブなど日替わりで価格が変わる材料が混じるレシピは差額を算出せず「変動あり」と表示

## 衣装ページ

- トップス・ボトムス・ワンピース・帽子・くつ・アクセサリー・バッグ・かさ・くつ下など、衣装として身につけられるアイテム全1487種類の売値を一覧表示
- カテゴリ絞り込み（1つだけ選択）、名前検索（ひらがな対応）、売値順・名前順のソート
- 各アイテムの入手方法（エイブルシスターズで購入／シャンクから／住民からもらう／季節イベント限定　など）を表示
- DIYで作れる衣装は入手方法のタグが「DIYで作る（DIYページ参照）」というリンクになっており、タップするとDIYページのそのアイテムのレシピへ直接ジャンプし、必要な材料を確認できる
- ハッピーホームパラダイスのオフィス制服など、そもそも売却できないアイテムは「売却不可」と表示

## 技術

- 依存ライブラリなしの単一HTMLファイル（`index.html` / `fossil.html` / `diy.html` / `clothing.html`）。サーバーサイド処理は無し
- PWA対応（`manifest.json`、`sw.js`、アイコン一式）
- 化石ページの収集状況は `localStorage` にブラウザ内保存（保存できない環境では一時的なメモにフォールバック）
- 生き物・化石のデータはCritterpedia準拠の出現データや各種攻略サイトの情報を、DIY・衣装のデータはコミュニティのデータマイニング情報（npm「animal-crossing」パッケージ）を基に作成・検証

## データについて

木にとまる虫の分類（広葉樹／針葉樹／ヤシの木）や、魚の釣り場（桟橋を含む）、化石の売値・部位構成、DIYの売値などは複数のソースを突き合わせて検証しています。ゲーム内の実際の仕様と差異があれば修正します。
