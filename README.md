# あつ森 売値サーチ

『あつまれ どうぶつの森』（北半球）の虫・魚・海の幸の売値をすぐに調べられる、図鑑型の検索ツールです。

**公開ページ：https://on6848.github.io/acnh-uriyaku-search/**

スマホのChromeで開いて「ホーム画面に追加」すると、アプリのようなアイコンから起動できます（PWA対応）。

## できること

- 虫・魚・海の幸のカテゴリ別に一覧・検索
- 名前での検索（ひらがな入力にも対応、例：「か」でカ行の名前がヒット）
- 検索時は完全一致を最優先で表示し、部分一致はクエリが名前の何文字目に出てくるかで並べ替え（同じ位置の中では選択中のソート順を適用）
- 価格の高い順・安い順・名前順のソート
- 出現月・出現時間帯での絞り込み（時間帯は具体的な時刻の範囲つき）
- 「今月獲れるものだけ」「今の時間に獲れるものだけ」の絞り込み（現在時刻と連動）
- 獲れる場所での絞り込み（魚：川・池・海・桟橋など／虫：地面・広葉樹・針葉樹・ヤシの木など）
- レア度を★1〜5で表示（カテゴリごとの価格分布から算出）
- 捕まえた／逃した済みのチェック管理
- 複数の生き物を選んで売値を比較（棒グラフ表示、上限なし）

## 技術

- 依存ライブラリなしの単一HTMLファイル（`index.html`）。サーバーサイド処理は無し
- PWA対応（`manifest.json`、`sw.js`、アイコン一式）
- データはCritterpedia準拠の出現データを基に作成・検証

## データについて

木にとまる虫の分類（広葉樹／針葉樹／ヤシの木）や、魚の釣り場（桟橋を含む）などは複数の攻略サイトを突き合わせて手作業で検証しています。ゲーム内の実際の仕様と差異があれば修正します。
